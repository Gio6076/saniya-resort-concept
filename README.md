# Saniya Resort & Hotel — Independent Website Concept

A production-minded hospitality website concept built as a flagship web-development portfolio project. The first milestone establishes the visual system, global shell, typed content architecture, responsive homepage, and booking entry point.

> Independent website concept created as a web-development portfolio project. This project is not affiliated with, commissioned by, or endorsed by Saniya Resort & Hotel.

## Stack

- Next.js App Router and TypeScript
- Tailwind CSS and Framer Motion
- React Hook Form and Zod
- date-fns and Lucide React
- Next/Image

## Local development

```bash
npm install
npm run dev
```

Open the local development URL shown by the `npm run dev` command.

## Quality checks

```bash
npm run lint
npm run build
```

## Current milestone

- Responsive navigation and mobile menu
- Global typography, color, spacing, radius, shadow, and focus conventions
- Structured mock data for stays, experiences, offers, gallery, and booking options
- Immersive editorial homepage
- Validated date and guest availability form
- Semantic structure, keyboard focus, and reduced-motion support
- SEO metadata and optimized responsive imagery
- Staged routes for the remaining experiences

The next milestone is the accommodations catalogue and room-detail experience, followed by the multi-step booking flow.
